# 적별 원형 투사체

2026-10-07. imagegen 내장 도구로 7종 원본을 각각 생성하고, 알파 영역 정리·최근접 32×32 축소·5색 팔레트 치환으로 테마별 28개 PNG를 내보냈다. 원본은 originals, 전체 생성 프롬프트와 원본 경로는 manifest.json에 보존했다. 재현 스크립트: tools/export-enemy-projectiles.ps1.

게임 리소스: Rushitadel2D/Assets/Resources/EnemyProjectiles/{Grass,Lava,Ice,WaterElectric}/{N01..N05,E01,E02}.png.

검증: 28개 PNG의 32×32 크기와 투명 모서리 검사 통과. 별도 Unity 프로젝트에서 탄 이미지 로딩·발사·지름 .768 판정 및 기존 보스 패턴을 포함한 444개 통합 검사 통과. 실행 캡처는 validation 폴더, 로그는 output/enemy-projectiles-validation.log. 회전한 사각 바운딩 박스 대신 스프라이트 로컬 크기에 월드 배율을 곱하여 원형 탄 지름을 검사한다.

| 적 번호 | 탄 외형 |
|---|---|
| N01 | 단일 씨앗 중심의 둥근 탄 |
| N02 | 세 포자 점이 들어간 원형 탄 |
| N03 | 두꺼운 장갑과 갈라진 중심의 중탄 |
| N04 | 십자 조준 문양의 원형 탄 |
| N05 | 세 갈래 소용돌이 탄 |
| E01 | 이중 링 장갑 탄 |
| E02 | 여섯 분할 장갑의 도탄 구슬 |

7종 형태를 4테마 팔레트로 구분한 28개 조합이며, 서로 완전히 다른 28개 실루엣은 아니다. 풀은 포자 분홍/살구, 용암은 주황/황금, 얼음은 자주/분홍, 물·전기는 보라/호박색으로 배경 및 청록색 아군 탄과 대비한다.

일반·정예의 HP, 속도, 도탄 횟수와 발사 패턴은 유지한다. 이전 .32 × 1.2 × 2 크기를 이어 지름 .768유닛 원형으로 표시하고 동일 치수의 캡슐(가로=세로, 원) 판정을 사용한다. PNG 바깥 2픽셀 여백은 런타임 스프라이트에서 제외한다. 보스와 플레이어 투사체는 변경하지 않는다. 적별 텍스처 머티리얼을 분리해 마지막 탄 이미지로 다른 탄이 바뀌는 문제를 방지한다.
