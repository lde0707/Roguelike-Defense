# 원거리 적 28종 디자인

모든 적은 절벽 위에서 길을 향해 투사체 또는 레이저를 발사하는 원거리 적이다. 근접 무기·접촉 공격을 특징으로 삼지 않는다. 일반 5종 + 엘리트 2종 × 4테마, 총 28종. 이번 작업은 이미지와 역할 제안이며 스폰/공격 AI를 변경하지 않는다.

## 아트 규격

- 개별 최종 파일: 32×32 RGBA PNG, 투명 배경, 아래쪽이 발사 방향인 높은 탑뷰.
- 일반은 최대 26px, 엘리트는 최대 28px 영역에 배치. 중앙 피벗 사용 권장.
- 매트한 돌·외피의 명암과 짙은 외곽선으로 맵과 질감은 맞추되, 바닥색을 복제하지 않는다.
- 풀: 자주색·뼈색 중심, 녹색은 작은 보조색. 용암: 차가운 회흑색·재색 + 주황 포구. 얼음: 남색·보라 외피 + 흰 결정. 물/전기: 남보라·산호색 + 황동 전극.
- Unity 권장: Sprite(Single), Point 필터, Compression None, Mip Maps Off, PPU 32. 현재 게임에 자동 배치하지 않았으므로 실제 월드 크기는 별도 결정한다.

## 제작 기록

imagegen 스킬의 내장 이미지 생성 모드로 개체마다 별도 생성했다. 정확한 프롬프트 28개는 jobs.json, 원본 파일 대응은 manifest.json에 있다. 원본은 originals에 보존한다. 최종 32×32 파일은 생성된 원본의 투명 여백을 정리하고 종횡비를 유지해 최근접 리샘플링한 결과다. catalog-4x.png는 최종 파일을 4배 확대해 확인하는 목록이며 실제 에셋 해상도는 32×32다.
