# 전투 아트 레트로 픽셀 교체

## 범위

- 일반·정예 원거리 적 28종: 4테마 × 7종, 투명 32×32 PNG.
- 적 종류별 탄 28종: 원형에 가까운 실루엣, 투명 32×32 PNG.
- 플레이어·포탑 탄/공격 효과 25종: 기본탄, 특수탄, 변형 포탑 16종 포함.
- 보스 탄/고리 22종, 레이저 몸통 6종, 나비 드론 1종.
- 합계 110개 런타임 이미지. 보스 본체·맵·사용하지 않는 기획용 스토리보드는 유지.

## 스타일 및 런타임 연결

- 내장 imagegen으로 각 에셋을 별도 생성. 단순한 덩어리, 제한된 색, 또렷한 도트 외곽선.
- 아군 탄: 청록/아이보리. 적 탄: 붉은 주황. 런타임 진영 셰이더는 유지.
- 기존 Resources 경로와 meta GUID를 유지하여 실제 전투에 연결.
- 크기·사거리·공격력·탄 체력·패턴은 변경하지 않음.
- 레이저는 64×16 몸통을 반복해서 표시하며 길이 방향으로 도트를 늘이지 않음. 충전 구체·모이는 입자·무해한 예고·발사/소멸 시간은 기존 동작 유지.
- 레이저의 기존 폭 보정 0.85와 피격판정 유지.

## 파일

- `enemies.json`, `shots.json`, `boss.json`: 최종 프롬프트와 생성 원본 경로.
- `originals/`: 프로젝트 내부에 보관한 생성 원본.
- `backups/`: 교체 전 PNG. 복원 가능.
- `*-preview.png`: 최종 픽셀 에셋 비교 시트.
- 런타임: `Rushitadel2D/Assets/Resources/{EnemyArt,EnemyProjectiles,ProjectileArt,BossArt}`.
- 재내보내기: `tools/export-combat-retro.ps1 -Manifest enemies.json` (shots.json, boss.json도 동일).

## 검증

세 비교 시트 및 Unity 전투 화면을 시각 확인했다. 최종 자동 검증 561개 항목 PASS (4테마 / 보스 20패턴 실행 / 16변형 포탑 비주얼). 32×32 Point 필터 적, 이미지 로딩, 피격판정 크기, 레이저 반복 타일과 정사각 픽셀 비율, 충전 중 무해 상태, 발사 및 제거 타이밍 등을 확인했다.

- 로그: `output/combat-retro-final-validation.log`
- 화면 및 결과: `in-game/`
- 최종 목록 110개 / 고유 리소스 110개 / 생성 오류 0개 / 누락 PNG 0개.
- 수동 장시간 플레이 밸런스 테스트를 대신하는 결과는 아니다.
