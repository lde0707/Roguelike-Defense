# 보스 패턴 Test 씬

Unity 메뉴 **Rushitadel → 보스 패턴 테스트 열기**를 누른 뒤 Play를 누릅니다.
직접 `Assets/Scenes/Test.unity`를 열어도 됩니다. 실행 시 실제 inGame 전장을 불러오며, 테스트 패널은 유지됩니다.

- 왼쪽에서 풀/불/얼음/물·전기 보스를 선택하면 즉시 해당 맵과 보스로 재시작합니다.
- 스테이지 1~3은 실제 체력/탄속/탄 HP 배율을 사용합니다.
- 페이즈 1~3을 고정하여 관찰할 수 있습니다.
- 패턴 선택의 ◀/▶ 버튼으로 전체 순환 또는 13개 개별 패턴 반복을 선택합니다. 전환 시 이전 탄·레이저·분신까지 전장을 새로 초기화합니다.
- 기본값은 무적 켜짐, 자동 포탑 공격 꺼짐입니다. 마우스 공격과 이동은 실제 게임과 같습니다.
- 0.5/1/2배 재생, Esc 일시 정지, Tab 패널 숨김, 다시 시작을 지원합니다.
- 물/전기 보스는 실제 개별 체력바를 사용합니다. 보스 처치 또는 플레이어 사망 후에도 다시 시작할 수 있습니다.
- 일반 웨이브, 추격 지형, 경험치 증강 팝업, 다음 라운드 진행을 하지 않습니다. 슬롯 0의 임시 세션이므로 기존 세이브를 쓰거나 덮어쓰지 않습니다.
- 테스트 종료 버튼으로 타이틀로 돌아가면 무적/페이즈 고정 등 테스트 기능은 해제됩니다.

## 구현

실제 CampaignBoss의 패턴 코루틴, 애니메이션, 발사체를 그대로 사용합니다. PreviewPhase/PreviewPattern은 기본값 -1로 일반 게임에 영향을 주지 않습니다.
검증 진입점: `Rushitadel.Editor.BossTestValidation.Run` (별도 검증용 프로젝트에서 사용).
