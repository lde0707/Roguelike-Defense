# Rushitadel 구현 현황

기준일: 2026-10-06. 문서의 기획 명세와 실제 Unity 구현을 구분한다. 최신 요청으로 레벨업 증강과 3라운드 마지막 보스 흐름을 적용했다.

## 반영 범위

| 범위 | 상태 |
| --- | --- |
| 루트 UI·시스템 PPT | 현재 플레이어 구조와 HP 기준, 기존 화면별 표·설명 양식 |
| 상세 TXT·게임 기획 MD | 현재 규칙·아트 기준·후보·미정 항목 |
| 성장 XLSX 2개 | 적용 대상 정합, Web 6가지, 변형 S3-01~15 ID 통일, 효과 후보 표시 |
| drawio | 런·전투·성장·저장 4개 페이지 |
| Unity 코드·씬·프리팹 | 이동·자전·부착 5포탑, 플레이어 HP와 패배, 적 공격, 동력, XP, HUD |

## 실행 가능한 범위

- 플레이어 본체에 5개 포탑을 72도 간격으로 부착한다.
- T1~T5 ID는 회전·이동 중 유지된다.
- 플레이어는 중앙 전장 안에서 이동하고 본체·포탑 리그가 자동 회전한다. 절벽의 보이지 않는 벽은 본체 반지름을 고려해 이동·반동을 막는다.
- 플레이어는 마우스 방향을 조준하고 좌클릭 유지로 원거리 직진탄을 발사한다.
- 포탑은 각자 정면으로 자동 사격하며, 발사한 포탄은 비유도로 3유닛 이동한다. 적 유무와 관계없이 발사하며 첫 적 충돌 또는 사거리 끝에서 소멸한다.
- 현재 씬의 원거리 적은 절벽 밖에서 플레이어 방향으로 탄을 발사한다. 근접 추적·접촉 공격은 별도 Enemy 프리팹으로 유지한다.
- 적 탄은 밖→안으로 들어올 때 통과하고, 안→밖으로 나갈 때만 반사한다. 한 프레임 안의 다중 반사와 경로 충돌을 검사한다.
- 적 탄에 HP가 있어 포탑탄·플레이어 기본탄·우클릭으로 파괴할 수 있다. 파괴된 탄은 XP를 지급하지 않는다.
- 피격 무적·회복 상한·사망 이벤트 단일 처리·패배 입력 차단을 제공한다.
- 동력은 공격에 소비되고 자동 충전된다. 고갈 후 60% 충전 시 잠금이 해제된다.
- 우클릭은 최대 기력 70%를 소비하고 짧게 후방 반동한다. 본체 지름 1.5배 원형 공격이 목표에 도착해 중앙 반지름 30% 즉사, 그 밖은 최대 HP 100%→50% 피해를 준다.
- 적 처치 위치에 파란 도트 XP 조각이 생긴다. 1~2초 대기 후 플레이어에게 날아와 자동 획득한다.
- 누적 XP 100마다 레벨업하고 포탑 대상 3택1 증강을 선택한다. 여러 레벨을 얻으면 선택을 순서대로 처리한다. 선택 중 전투는 완전 정지한다.
- 3라운드 × 3스테이지 진행, 각 3라운드의 마지막에 보스 등장, 총 3보스 격파 후 승리한다. 라운드 종료마다 안전 정비에서 HP/동력 회복과 6노드 XP Web 구매를 제공한다.
- XP Web 소비와 레벨 계산용 누적 XP는 분리한다. 구매로 레벨이 내려가지 않는다. 관통·분산·폭발·독·동력·지원 효과를 실제 기본 공격/플레이어 스탯에 적용한다.
- 상단에 스테이지·라운드·스폰/잔여 적·보스 HP와 상태, 하단 외곽에 HP·동력·레벨·XP·T1~T5 정보를 표시한다. 양쪽 절벽의 적을 HUD로 가리지 않는다.
- 안전 정비·회복·Web 구매·다음 라운드 시작을 저장한다. 3슬롯 이어하기는 진행·증강·Web·회복 완료 여부를 복원한다.
- 일시정지·재개·패배·재시작·타이틀·새 게임을 제공한다.
- 카메라가 독립적으로 전진하며 반복 타일 배경이 화면 아래로 흐른다. 정지한 플레이어는 뒤로 밀려 후방 위험 구역에 노출된다.
- 카메라 하단 테마 위험 구역과 상단 장벽을 고정한다. 후방 접촉 1초마다 최대 HP 50% 환경 피해, 상단 이동·반동 차단을 제공한다.
- 독안개·용암·눈보라·해일·전기폭풍의 프로토타입 팔레트·형태를 전환할 수 있다. 스테이지별 테마 2택1과 런 중 중복 제외를 연결했다. 최종 테마별 맵·VFX 교체는 별도다.
- 적은 카메라 전방 좌우에 생성되고 뒤로 지나간 적은 보상 없이 정리된다. 일시정지·패배에는 진행과 위험 구역 타이머도 정지한다.

마우스 원거리 공격, 포탑 정면 비유도탄·약 3유닛, 절벽 단방향 도탄·적 탄 HP, 우클릭 70%/1.5배/30%/50%는 확정된 전투 기준이다. 발사 간격·일반 피해·반동 거리·충전 속도 등 테스트값은 최종 밸런스 승인을 대신하지 않는다.

## 명세 단계 기능

| 기능 | 남은 구현 |
| --- | --- |
| 테마 | 테마별 최종 맵·적·고유 보스 리소스 연결 |
| 성장 | 증강 후보 확장과 밸런스. 현재 화력/발사 빈도/관통 3종 구현 |
| XP Web | 현재 6노드 이후 확장 데이터와 밸런스 |
| 보스 | 현재 공통 도트 감시자 3단계, 부채꼴·전방위·조준 3연탄. 최종 테마별 보스는 별도 |
| 저장 | 전투 중 임의 시점 전체 시뮬레이션 스냅샷은 지원하지 않음 |
| 최종 아트·UI | 플레이어·압박 VFX의 기존 임시 도형 교체. 한글 Neo둥근모 도트 폰트 적용 완료 |

유효한 저장이 있으면 Continue가 활성화된다. 최신 구현 규칙·수치는 [성장/캠페인 구현](../Rushitadel2D/Documentation/Campaign.md)을 참고한다. 예전 PPT의 +3·6·9·12 증강 및 3회차 정비 뒤 보스 흐름보다 이번 사용자 요청이 우선한다.

## 테스트 기본값

실행 수치는 [Unity 실행 안내](../Rushitadel2D/README_2D.md)에 모았다. HP 100, 이동 2.5, 회전 30도/s, 포탑 피해 25·간격 0.5초, 기본탄 피해 25·간격 0.25초·사거리 8, 동력 최대 100·충전 5/s, 반동 0.18유닛·0.12초, 적 탄 HP 25·피해 10·탄속 4·수명 12초는 조정 가능한 테스트 기본값이다.

플레이어·적·투사체·테마 압박 표현은 임시 도형이다. 맵은 연결 타일 배경을 실제 반복 스크롤에 사용한다. 카메라 전진 0.8유닛/초·후방 최대 HP 50%/초도 테스트값이며 튜닝 가능하다. 시각 크기와 충돌 영역은 따로 관리한다.

## 검증

Unity 6000.5.3f1에서 씬 생성·스크립트 컴파일 후 실제 Play Mode 회귀 테스트가 통과했다.

검사 범위: 슬롯·자전·이동·마우스 사격, 절벽 차단·반동, 밖→안 진입·안→밖 반사·고속 다중 반사, 적 탄 HP·포탑/플레이어 파괴·XP 제외, 우클릭 최대 기력 70%·지름 1.5배·중앙 즉사·외곽 비례 피해·원 밖 제외, XP, 일시정지, 패배, 타이틀·새 게임 초기화.

전진 압박 검사: 입력 없는 플레이어의 화면 후퇴, W 전진, 상단 통과·반동 차단, 후방 초당 피해·피격 무적과 독립, 영역 이탈·일시정지 타이머, 5개 테마 전환, 반복 배경 이음새·긴 진행 좌표, 카메라 이동 중 적 탄 좌표 유지, 전방 적 생성·후방 정리.

검증 증거와 경계: [Validation](../Rushitadel2D/Documentation/Validation.md). 스탠드얼론 실행 파일 빌드·장시간 밸런스·최종 HUD 시각 검수는 별도다.
