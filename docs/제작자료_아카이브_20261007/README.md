## 상태를 읽는 법

- 사용자 요구: 대화에서 요청·확인된 방향이다.
- 설계 초안: 제안한 패턴·수치이며 사용자 최종 승인이나 플레이테스트 완료를 뜻하지 않는다.
- 구현 기록: 기존 구현 문서의 기록을 보존한 것이다. 이번 작업에서 Unity를 재실행하여 검증하지 않았다.
- 이미지: 생성 컨셉 원본과 참고 첨부다. 최종 채택, 피벗·프레임 정렬, 게임 크기, 알파 품질까지 모두 검증한 완성 스프라이트라는 뜻은 아니다.

## 보존 자료

- 현재 대화 ID 전용 생성 폴더의 이미지 365개를 `이미지/생성원본`에 복사하고 SHA-256 일치를 확인했다. 미채택·수정 전 시안도 포함된다.
- 대화에 명시된 첨부 이미지 32개 중 로컬에 남아 있는 23개를 `이미지/첨부참고`에 복사했다.
- 기존 프로젝트 이미지 150개는 원래 폴더에서 유지하고 목차로 연결한다.
- 기존 Markdown 9개는 `기존문서` 아래 상대 경로를 유지해 스냅샷으로 복사했다.
- 모든 과거 대화 원문을 내보낸 자료는 아니다. 확인 가능한 대화 내용의 구조화 요약과 기존 문서 원문을 보존했다. UUID 생성 이미지의 개별 주제·채택 여부는 추정하지 않는다.
