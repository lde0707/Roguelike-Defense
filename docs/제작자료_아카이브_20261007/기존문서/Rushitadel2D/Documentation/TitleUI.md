# 타이틀 UI 구현 · 2026-10-06

## 실행

Unity 6000.5.3f1에서 프로젝트를 열고 Play를 누르면 Title 씬부터 시작한다. 빌드 씬 순서는 Title → inGame이다. 런타임 UI는 GameFrontend가 만들며 기존 Title Canvas는 비활성화한다.

## 화면과 기능

- 게임 시작: 3개 저장 슬롯 → 테마 후보 2개 중 선택 → 확정 후 전투. 기존 슬롯은 덮어쓰기 확인 후에만 교체한다.
- 이어하기: 유효한 저장이 있을 때 활성화. 슬롯의 최근 안전 저장 지점으로 복귀한다. 손상·버전 불일치 파일은 보존하고 불러오기를 차단한다.
- 설정: 표시(지원 해상도, 화면 모드, FPS, VSync), 사운드(전체/BGM/효과음), 조작 안내. 음량 즉시 미리 적용, 취소 복구, 적용 저장. 화면 변경은 15초 내 유지하지 않으면 복구한다.
- 게임 종료: “게임을 종료하시겠습니까?” 확인 후 종료. Editor에서는 Play 종료, 실행 파일에서는 Application.Quit.
- ESC: 일시정지 → 계속하기/설정/타이틀/종료. 설정에서 돌아와도 전투는 정지 상태를 유지한다. 타이틀·종료 시 최근 저장 이후 진행 손실을 안내한다.

## 설정 선택 방식 · 2026-10-06 추가

- 선택지 4개 이상: 아래로 펼쳐지는 3행 높이 목록. 휠과 우측 스크롤바 클릭/드래그로 탐색하고 항목을 클릭해 선택한다. ESC 또는 바깥 클릭으로 닫는다.
- 화면 모드 3종, VSync 2종은 클릭 순환을 유지한다. 해상도와 FPS 제한은 드롭다운이다.
- 해상도: 1280×720 / 1600×900 / 1920×1080 / 2560×1440 / 3840×2160. 저사양용 720p·900p와 16:9 FHD·QHD·4K를 남기고 모니터의 기타 모드 자동 나열은 제거했다. QHD·4K 선택은 [Steam 하드웨어 조사](https://store.steampowered.com/hwsurvey/)를 참고했다.
- 목록 선택은 초안만 변경한다. 적용/취소와 15초 화면 복구는 기존대로 유지한다. 미지원 독점 전체 화면 해상도는 적용하지 않고 안내한다. 실제 화면 전환은 독립 실행 파일에서 추가 확인해야 한다.
- 플레이어 기본탄·포탑탄·적 탄은 시각 크기 20% 증가, 피해/충돌 판정은 유지. 우클릭 탄은 비행 중 20% 커지고 착탄 시 원래 피해 범위를 표시한다. 포탑 사거리는 3유닛이다.

## 아트

### 씬 전환 · 도트 셔터

새 게임의 테마 확정, 이어하기, 타이틀 복귀 시 공통 적용한다. 무광 남청색 24행 패널이 양옆에서 0.30초 동안 닫히고, 완전히 가린 한 프레임 이후 비동기 씬 로드를 시작한다. 세션·캠페인·HUD 초기화가 끝난 뒤 최소 0.08초 유지하고 0.42초 동안 중앙에서 바깥으로 열린다. 8픽셀 단위 이동, 행별 작은 시차, 엇갈리는 중앙 이음부를 사용한다. 로드가 0.5초를 넘으면 준비 문구의 점이 순환한다.

별도 최상단 Canvas를 사용하므로 페이지 교체나 씬 로드 중 셔터가 사라지지 않는다. 투명 입력 차단판과 중복 로드 방어를 적용한다. 전환 애니메이션은 비시간배율 시간으로 동작하며, 닫기 시작부터 열기 완료까지 게임 시간과 조작을 잠근다. 완료 후 캠페인 상태를 다시 표시하여 정비/증강 저장을 불러온 경우에는 정지 상태를 유지한다. 씬 로드 실패 시 덮개를 해제하고 오류를 표시한다. 효과는 `GameFrontend.Transition.cs`에서 조정한다.

Unity 자동 검증: 새 게임, 이어하기, 타이틀 복귀, 전환 중 시간 정지 및 입력 잠금, 전환 종료 후 정리/전투 재개. 캡처: `output/title-implementation-20261006/shutter-closing.png`, `shutter-opening.png`. 로그: `output/shutter-validation.log`.

타이틀 배경은 아래 방향으로 초당 18 기준 픽셀씩 무한 스크롤한다. 상하 미러 반복으로 빈틈 없이 이어지며, 타이틀의 하위 메뉴에서도 스크롤 위치를 유지한다. 로고와 버튼은 고정된다. `Time.unscaledDeltaTime`을 사용하므로 정지 UI에서도 동작한다.

타이틀에서 커서 주변 반지름 36 기준 픽셀의 원 안에 있는 UI RGB를 반전한다. 3픽셀 격자 경계로 도트 느낌을 유지하고 알파/클릭 판정은 바꾸지 않는다. 배경에는 반전을 적용하지 않으며, 확인 팝업·다른 페이지·게임 플레이·창 포커스 이탈에서는 반전을 끈다. 기존 hover/pressed 스프라이트와 함께 동작한다. `GameFrontend.TitleEffects.cs`의 속도/반지름 상수로 조정할 수 있다. 셰이더는 Resources에 포함해 빌드에서도 로드하며 런타임 생성 Material은 프런트엔드 종료 시 해제한다.

Assets/Resources/TitleUI에 로고, 배경, 4개 버튼의 Normal/Hover/Pressed PNG를 개별 저장했다. Point 필터, 압축·밉맵 없음. 이어하기 비활성은 색을 낮춘다. 기본 무광 세이지색과 어두운 실제 맵 텍스처를 사용하며 발광은 추가하지 않았다.

버튼 원화는 내장 이미지 생성 도구로 제작했다. 원본과 프롬프트는 저장소 루트 output/title-implementation-20261006/button-states.png 및 button-states.json이다. Rushitadel/Prepare Title UI Assets 메뉴로 개별 에셋을 재생성할 수 있다. 이 메뉴는 원본 output 파일들을 필요로 한다.

## 저장과 현재 구현 범위

Application.persistentDataPath/Runs/slot1.json~slot3.json에 저장한다. 임시 파일 검증 후 원자적 교체하고 이전 저장은 .bak으로 유지한다. 체크섬, 스키마, 필수 값 검증을 적용한다. 설정은 PlayerPrefs Rushitadel.Settings.v1이다.

캠페인은 3라운드 × 3스테이지로 진행한다. 테마 확정, 라운드 종료 정비, 회복·Web 구매, 다음 라운드 시작과 완료 시 저장한다. HP, 동력, 누적 경험치와 사용 XP, 위치, 카메라 진행, 포탑 회전, 테마, 시드, 경과 시간, 포탑 증강과 Web을 복원한다. 전투 중 적·탄의 상태를 그대로 재현하는 중간 저장은 아니다. 저장 v1은 v2로 읽기 마이그레이션하며 원본은 다음 저장의 백업으로 유지한다. 자세한 규칙은 Campaign.md를 참고한다.

테마 선택은 현재 테마별 추격 효과에 연결한다. 전체 테마 스테이지/보스 콘텐츠를 생성하는 기능은 아니다. 사운드 설정은 AudioChannel로 분리 적용하며 UI 효과음을 포함한다. 프로젝트에 BGM 음원이 없으므로 실제 음악을 추가하려면 AudioSource와 music=true인 AudioChannel을 연결한다. 조작 탭은 고정 키 안내이며 키 재지정은 포함하지 않는다.

## 검증

TitleUiValidation.Run으로 Unity Play Mode 자동 검증을 수행한다. 테스트 저장은 output 아래 별도 폴더를 사용하므로 사용자 슬롯을 덮어쓰지 않는다.

검증 항목: 타이틀 진입, 버튼 hover sprite 교체, 종료 취소, 음량 미리 적용/취소/저장 재로드, 화면 변경 타임아웃 복구, 슬롯/테마 선택, 실제 게임 진입, 안전 저장과 백업, HP·경험치 이어하기 복원, 일시정지/설정 복귀, 손상·버전·NaN 데이터 거부, 덮어쓰기 취소.

추가 검증 통과: 해상도 5종/QHD·4K 목록, 3선택지 순환 유지, 드롭다운 휠 및 스크롤바 위치 변경, 선택값 초안 반영, 바깥 클릭 닫기, 기본·포탑·적 탄 20% 확대, 우클릭 피해 반경 유지, 씬 포탑 5기 사거리 3 및 포탄 정확히 3유닛 소멸. 로그: `output/settings-projectile-validation-3.log`의 `RUSHITADEL_TITLE_UI_VALIDATION_SUCCESS`.

화면 캡처와 로그는 output/title-implementation-20261006에 있다. 독립 실행 파일의 해상도 전환과 OS 종료 동작은 별도 수동 QA가 필요하다. 에디터의 Game 창 크기는 해상도 설정으로 변경하지 않는다.
