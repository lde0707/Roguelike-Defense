# 경험치 · 성장 · 3스테이지 캠페인

2026-10-06 사용자 요청 기준. 이전 PPT의 강화 +3/+6/+9/+12 증강 규칙보다 이번 레벨업 3택1 요청을 우선한다. 예전의 3회차 정비 후 별도 보스전 대신 3라운드 마지막에 보스를 배치한다.

## 진행 흐름

타이틀 → 슬롯/테마 → 1라운드 → 안전 정비 → 2라운드 → 안전 정비 → 3라운드 일반 적 → 보스 → 안전 정비 → 다음 스테이지 테마.

이 흐름을 총 3스테이지 진행한다. 마지막 정비의 ‘런 완료’에서 승리 화면으로 이동한다. 각 스테이지는 3라운드이며 전체 9라운드, 보스 3회다. HP 0이면 즉시 패배하고 전투·선택 입력을 멈춘다.

일반 적은 유한 스폰 예산을 사용한다. 스폰 완료 후 생존 적이 없어야 종료한다. 화면 뒤로 지나가 정리된 적은 XP를 주지 않는다. 3라운드 마지막에는 공통 도트 감시자 보스가 등장한다. 보스는 부채꼴 5발, 전방위 구체, 조준 고정 3연탄을 번갈아 쏜다. 충전 점멸과 HUD 상태를 표시하고 회복 시간을 둔다. 보스전에는 카메라 전진을 멈춘다. 최종 테마별 고유 보스 아트·패턴은 이번 공통 보스와 별도다.

## 경험치와 증강

- 적 사망 위치에 파란 픽셀 결정 드롭. 1~2초 대기 후 흡수 이동. 획득과 레벨 계산은 한 번만 처리한다.
- XP 100당 1레벨, 시작 LV1. 한 번에 여러 레벨을 얻으면 선택을 큐처럼 순차 처리한다.
- 선택 화면에서 대상 T1~T5 → 3개 카드 중 선택 → 확정한다. 선택 중 이동·공격·탄·카메라·자동 회복은 정지한다. ESC 일시정지 뒤 돌아와도 미완료 선택을 유지한다.
- 현재 기본 증강 풀은 강화 포신(피해 +25%), 고속 장전(발사 빈도 +20%), 관통 탄두(추가 대상 +1)다. 선택한 포탑에만 적용하며 정면 비유도 사격은 유지한다.
- 반복 선택은 해당 효과의 랭크를 올린다. 중복 버튼 입력으로 추가 지급하지 않는다.

## 안전 정비와 XP Web

잔여 XP 조각을 전부 흡수하고 레벨업 선택을 마친 후 정비한다. 적 탄과 아군 탄을 정리하고 플레이어를 중앙 안전 위치에 놓는다. 정비 동안 전투는 완전 정지한다.

HP 30% 또는 동력 +50 회복 중 하나를 선택한다. 자원이 최대면 해당 카드는 비활성이다. 건너뛰기도 가능하다. 회복 완료 여부를 저장하여 재접속 중복 회복을 막는다.

Web 소비용 XP = 누적 획득 XP - 사용 XP다. 구매로 레벨을 낮추지 않는다. 선행 연결, 비용, 미구매 조건을 검사한다. 포탑 증강과 달리 Web은 플레이어에 적용한다.

## HUD / 픽셀 표현

UI-06의 전장/정보 영역 분리 원칙에 맞춰 중앙 전투 영역을 비우고 상단 진행 바와 하단 자원/포탑 영역을 사용한다. 좌우 절벽 위 적을 가리지 않도록 HUD는 좌우 중앙에 놓지 않는다. 보스 이름·HP·상태, 스테이지·라운드·스폰 수·잔여 적·HP·동력·레벨·XP를 실제 값으로 갱신한다.

이번 XP 결정·절벽 적·공통 보스는 Point 필터의 작은 도트 스프라이트다. UI는 정수 좌표의 각진 무광 패널과 픽셀 스냅을 사용한다. 한글은 공식 Neo둥근모 v1.601 도트 폰트를 Resources/Fonts에 포함했다. 같은 폴더에 SIL OFL 1.1 라이선스 원문을 동봉했다. 출처: https://github.com/neodgm/neodgm/releases/tag/v1.601 . 기존 플레이어/추격 VFX는 이 작업에서 최종 아트로 교체하지 않았다.

## 저장과 조정 지점

RunStore v2에 캠페인 단계, 라운드, 완료 보스, Web 구매, 소비 XP, 증강 랭크·완료 선택 수, 회복 완료, 테마 후보를 저장한다. v1 데이터 읽기를 지원한다. 정비/출발 시점 저장이며 전투 중 강제 종료하면 최근 안전 지점부터 재개한다.

테스트값: 라운드 적 수 = 8 + 스테이지×2 + 라운드×2, 간격 1.7초, 동시 최대 8. 일반 적 HP = 60 + 스테이지×20, XP20. 보스 HP = 450 + 스테이지×200, XP100. CampaignDirector, EnemySpawner, CampaignBoss의 상수/필드에서 조정한다. 이 값은 최종 밸런스 확정을 의미하지 않는다.

검증 진입점: Rushitadel.Editor.CampaignValidation.Run. 전용 테스트 저장 폴더만 사용하고 사용자 슬롯은 수정하지 않는다. 화면 증거는 output/campaign-validation-20261006에 저장한다. 자동 진행은 적을 테스트 코드로 제거하여 상태 전이/보상/저장을 검증하므로 실제 난이도 플레이테스트를 대신하지 않는다.

검증 완료: 1~2초 XP 대기와 자동 수집, 다중 레벨업 큐, ESC 후 증강 복귀, 중복 선택 차단, 관통/폭발/독의 실제 HP 변화, Web 연결/비용/중복 차단, 최대 HP 반영, 정비 체크포인트 복원, 중복 테마 제외, 실제 보스 발사, 9회 정비와 3보스·승리·완료 저장. 기존 TitleUiValidation도 통과했다. 로그: output/campaign-verified.log, output/campaign-title-regression.log.
