# 타이틀 UI 구현 · 2026-10-06

## 실행

Unity 6000.5.3f1에서 프로젝트를 열고 Play를 누르면 Title 씬부터 시작한다. 빌드 씬 순서는 Title → inGame이다. 런타임 UI는 GameFrontend가 만들며 기존 Title Canvas는 비활성화한다.

## 화면과 기능

- 게임 시작: 3개 저장 슬롯 → 테마 후보 2개 중 선택 → 확정 후 전투. 기존 슬롯은 덮어쓰기 확인 후에만 교체한다.
- 이어하기: 유효한 저장이 있을 때 활성화. 슬롯의 최근 안전 저장 지점으로 복귀한다. 손상·버전 불일치 파일은 보존하고 불러오기를 차단한다.
- 설정: 표시(지원 해상도, 화면 모드, FPS, VSync), 사운드(전체/BGM/효과음), 조작 안내. 음량 즉시 미리 적용, 취소 복구, 적용 저장. 화면 변경은 15초 내 유지하지 않으면 복구한다.
- 게임 종료: “게임을 종료하시겠습니까?” 확인 후 종료. Editor에서는 Play 종료, 실행 파일에서는 Application.Quit.
- ESC: 일시정지 → 계속하기/설정/타이틀/종료. 설정에서 돌아와도 전투는 정지 상태를 유지한다. 타이틀·종료 시 최근 저장 이후 진행 손실을 안내한다.

## 아트

Assets/Resources/TitleUI에 로고, 배경, 4개 버튼의 Normal/Hover/Pressed PNG를 개별 저장했다. Point 필터, 압축·밉맵 없음. 이어하기 비활성은 색을 낮춘다. 기본 무광 세이지색과 어두운 실제 맵 텍스처를 사용하며 발광은 추가하지 않았다.

버튼 원화는 내장 이미지 생성 도구로 제작했다. 원본과 프롬프트는 저장소 루트 output/title-implementation-20261006/button-states.png 및 button-states.json이다. Rushitadel/Prepare Title UI Assets 메뉴로 개별 에셋을 재생성할 수 있다. 이 메뉴는 원본 output 파일들을 필요로 한다.

## 저장과 현재 구현 범위

Application.persistentDataPath/Runs/slot1.json~slot3.json에 저장한다. 임시 파일 검증 후 원자적 교체하고 이전 저장은 .bak으로 유지한다. 체크섬, 스키마, 필수 값 검증을 적용한다. 설정은 PlayerPrefs Rushitadel.Settings.v1이다.

캠페인은 3라운드 × 3스테이지로 진행한다. 테마 확정, 라운드 종료 정비, 회복·Web 구매, 다음 라운드 시작과 완료 시 저장한다. HP, 동력, 누적 경험치와 사용 XP, 위치, 카메라 진행, 포탑 회전, 테마, 시드, 경과 시간, 포탑 증강과 Web을 복원한다. 전투 중 적·탄의 상태를 그대로 재현하는 중간 저장은 아니다. 저장 v1은 v2로 읽기 마이그레이션하며 원본은 다음 저장의 백업으로 유지한다. 자세한 규칙은 Campaign.md를 참고한다.

테마 선택은 현재 테마별 추격 효과에 연결한다. 전체 테마 스테이지/보스 콘텐츠를 생성하는 기능은 아니다. 사운드 설정은 AudioChannel로 분리 적용하며 UI 효과음을 포함한다. 프로젝트에 BGM 음원이 없으므로 실제 음악을 추가하려면 AudioSource와 music=true인 AudioChannel을 연결한다. 조작 탭은 고정 키 안내이며 키 재지정은 포함하지 않는다.

## 검증

TitleUiValidation.Run으로 Unity Play Mode 자동 검증을 수행한다. 테스트 저장은 output 아래 별도 폴더를 사용하므로 사용자 슬롯을 덮어쓰지 않는다.

검증 항목: 타이틀 진입, 버튼 hover sprite 교체, 종료 취소, 음량 미리 적용/취소/저장 재로드, 화면 변경 타임아웃 복구, 슬롯/테마 선택, 실제 게임 진입, 안전 저장과 백업, HP·경험치 이어하기 복원, 일시정지/설정 복귀, 손상·버전·NaN 데이터 거부, 덮어쓰기 취소.

화면 캡처와 로그는 output/title-implementation-20261006에 있다. 독립 실행 파일의 해상도 전환과 OS 종료 동작은 별도 수동 QA가 필요하다. 에디터의 Game 창 크기는 해상도 설정으로 변경하지 않는다.
