# 회전 포탑 변형 구현

기준: `Rushitadel_회전포탑_변형증강.xlsx`의 회전형 변형 ROT-01~16.

## 사용

타이틀 → 게임 시작 → 레벨 상승 → **변형 포탑 선택** → T1~T5 → 3개 후보 중 선택 → 변형 확정.
한 번의 레벨업 선택을 소비한다. 같은 선택을 다시 열어도 후보가 바뀌지 않는다. 복제/과충전 지원형은 전체 5개 포탑 중 1개만 장착 가능하다.
일반 강화의 기존 화력/연사 수치는 유지한다. 변형 고유 타격 수 제한은 관통 강화로 늘어나지 않는다. 지원형 화력, 냉각 분사포 연사, 변형 포탑 관통 등 적용되지 않는 일반 강화는 선택을 막았다.

안전 정비의 회복 선택 후 **플레이어 속성 발광**에서 기본/불꽃/얼음/전기/독/물 색상을 변경한다. 금속 외장은 유지하고 발광부, 광원, 변형탄 색상만 변경한다. 이 메뉴는 시각 속성 선택이며 별도의 속성 피해 배율이나 추가 상태이상을 주지 않는다. 냉각/부식 포탑의 고유 상태이상은 발광 색과 독립적이다.

## 공격

포탑은 자신의 정면으로 발사한다. 발사/설치 후에는 본체 회전과 분리된 월드 좌표를 사용한다. 사거리 제한은 발사 원점 기준 3유닛이다. 적 탄 HP를 실제로 차감하며 처치 경험치는 만들지 않는다.

복제/과충전은 호환 변형 01~05, 07, 09, 12, 16에 적용한다. 복제탄/분열 파편은 다시 복제하지 않으며 복제 부식 지속시간은 절반이다. 기본 포탑탄과 플레이어 수동 공격은 이 표식 적용 대상에 포함하지 않는다.

## 아트와 발광

`Assets/Resources/PlayerForms/Hull.png`는 48×48, 기본 `Default.png`와 `ROT-01.png`~`ROT-16.png`는 각각 24×24 RGBA 도트다. 본체와 포탑을 분리하고 실제 5개 장착점을 기준으로 회전한다. Point 필터/무압축/알파를 `PlayerArtImporter`에서 유지한다. 본체는 전체 캔버스 중심을 회전축으로 쓰며, 포탑은 투명 여백을 제외한 높이를 정규화하여 포구가 기존 발사 위치에 맞게 배치된다.

imagegen 스킬의 내장 이미지 생성/편집 모드를 사용했다. 선택된 5엽 터빈을 기준으로 저채도 자주색 장갑·낡은 황동·청회색 프레임·따뜻한 소형 발광부를 통일했다. 각 ID의 쌍열/산탄/드릴/원반 슬롯/구체/분사/분무/표식/부메랑/톱날/파동/십자/그물/과충전/포말/도체 실루엣을 엑셀에 맞췄다. 생성 원본, 프롬프트, 교체 전 백업과 도트 내보내기 스크립트는 `output/imagegen/turbine-unity-20261007`에 보관한다.

`ModularPlayerArt` / `TurretVisual`: 외형 교체, 포탑별 스프링 반동·짧은 점멸, 회전 잔상과 부유 그림자. 물리 회전 속도와 발사 방향은 유지한다.
`PlayerFlightEffects`: 코어 맥동, 약한 부유, 이동 관성과 꼬리 잔광, 일반 공격 섬광, 강공격 확장 파동. 실제 공격 성공 이벤트에 연결하며 쿨다운·파워 부족·일시정지에는 발동하지 않는다. 효과 32개를 재사용하고 발사된 섬광은 월드 좌표를 유지한다. 일시정지 시 모든 연출 시간을 멈춘다.
`ElementSprite.shader`: 밝은 램프 픽셀만 속성 색상 치환. 네 번의 텍셀 샘플로 회전 중 가장자리 커버리지를 보정한다.
`FlightVfx.shader`: 작은 도트 광륜·파동·포구 섬광·이동 잔광·회전 공기 흐름.
`TransformationShot`: 월드 좌표 공격, HP 처리, 상태이상, 표식, 파편, 연쇄.
`CampaignState` / `RunStore`: 변형 ID·선택 횟수·속성 색상 저장/복원 및 기존 저장 호환.

## 투사체 디자인

`Assets/Resources/ProjectileArt`에 별도 투명 도트 자산 49개를 둔다. 기본 3개(플레이어 일반·동력·기본 포탑), ROT 16개, 정리본 v2의 S3 15개, 이전 기획의 방패 지원 토큰 1개, Web 4개, 파편·소형 미사일·프리즘탄·폭발·잔류 영역·산성 웅덩이·독·냉각·표식·보호막 보조 자산 10개다. 작은 탄은 16×16, 드릴·원반·미사일은 24×24, 범위·설치형 효과는 32×32로 내보낸다.

`ProjectileArt` / `ProjectileVisual`은 기존 공격 오브젝트의 자식에 외형을 적용한다. 투사체 루트, 충돌체, 피해·사거리·개수 제한을 바꾸지 않는다. 실제 적용 범위는 플레이어 일반/동력탄, 기본 포탑탄, ROT-01~16, 현재 Web 강화탄과 독·냉각 상태다. 복제탄은 외형만 작고 옅어지며, 과충전은 테두리가 생긴다. 우클릭 넉백은 없다.

v2 S3 포탑과 아직 구현되지 않은 증강 효과는 사용 가능한 이미지로 준비하며 새로운 전투 규칙을 추가하지 않는다. `S3-13` 전격 이미지는 현재 ROT-16의 연쇄선에도 사용한다. 구 기획의 `S3-04`는 드릴, v2의 `S3-04`는 저격이므로 동일 ID라고 외형을 덮어쓰지 않는다. 엑셀 131개 행과 자산의 대응표, 프롬프트, 생성 원본, 3장 미리보기는 `output/imagegen/projectiles-20261007`에 있다. 내장 image_gen으로 생성한 뒤 최근접 샘플링으로 실제 도트 크기를 맞췄다.

## 검증

2026-10-08 최종 투사체 자산으로 `TransformationValidation.Run`의 268개 검사를 통과했다. 49개 텍스처 크기·Point 필터·투명도·스프라이트 로딩, 16종 실제 발사 외형, 기존 피해·관통·설치 개수·지원문·저장 복원, 수동/동력 공격 외형, 외형 교체 시 충돌체 유지, 우클릭 넉백 없음까지 확인했다. 로그와 실제 게임 캡처는 `output/projectile-validation`에 저장했다. 신규 S3 전투 규칙은 구현/검증 대상이 아니며 디자인 자산만 제공한다.

회전/공격 연출은 `Rushitadel.Editor.FlightValidation.Run`으로 검증한다. 별도 프로젝트 복사본 `.work/fv`에서 실행해야 한다(완료 시 에디터를 종료한다). 48/24px 크기, 5개 장착, 기본+16종 외형 연결과 실제 발사 이벤트, 회전·idle, 물리 위치 유지, 공격 쿨다운·파워 부족·일시정지 연출 차단을 검사한다. 2026-10-07 Unity 6000.5.3f1에서 62개 검사 통과. 20fps 게임 렌더 80장과 GIF는 `output/flight-validation`에 저장했다. 새 배치 프로젝트에서 발생하는 UnityEditor.Search 인덱스 예외만 하네스 종료 조건에서 제외하며, 게임 코드·셰이더 오류는 실패 처리한다.

Unity 6000.5.3f1에서 `Rushitadel.Editor.TransformationValidation.Run`을 실행한다. 테스트 저장은 `output/transformation-20261007/test-saves`로 격리한다.
컴파일, 16개 스프라이트 로딩, 실제 포탑 발사, 개별 피해/타격 상한, 시간차 공격, 둔화/부식/밀치기, 설치 개수, 재복제 방지, 3유닛 수명, 16종 선택·외형 연결, 지원형 제한, 속성 색상, 저장 복원을 검사한다.
실제 맵 위 기본/불꽃/얼음 이미지와 여러 회전각 확대 캡처를 `output/transformation-20261007`에 저장한다.

단위 동작 검증과 별개로 전체 9라운드 난이도, 다수 적탄에서의 장시간 성능, 모든 포탑 조합의 DPS 밸런스는 후속 플레이테스트가 필요하다. 수치는 엑셀의 초안 값을 옮긴 것이며 최종 밸런스로 확정한 것은 아니다.
