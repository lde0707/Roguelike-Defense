# 플레이어 Web 아이콘 트리

## 원본

`Rushitadel_증강_정리본v2.xlsx`의 `01_플레이어Web` 시트 4~27행을 그대로 읽어 24개 항목을 표시한다. 데이터는 `Resources/WebIcons/Catalog.json`에 저장되어 있으며 원본 행 번호를 포함한다. 엑셀 파일은 수정하지 않았다.

## 화면

- 화면 중앙 하단 시작점 → 기초 6개 → 관통·분산·폭발·독·지원·동력 가지.
- 각 가지는 핵심 하나와 보조 두 개로 구성된다. 선은 구매 선행 조건의 확정안이 아닌 UI 배치 제안이다.
- 아이콘을 클릭하면 우측 하단 고정 패널에 이름·가지·등급·효과·역할이 나타난다.
- 클릭으로 XP를 소비하지 않는다. 게임은 정비 중 일시정지 상태를 유지한다.
- 아이콘은 내장 imagegen으로 생성한 32×32 PNG. Point 필터로 64×64 표시한다. 과한 발광 없이 매트한 레트로 팔레트를 사용한다.
- Title 씬의 `08 플레이어 Web` 페이지에서 편집기 미리보기가 가능하다.

## 구현 범위와 기존 강화

엑셀 24종과 현재 게임의 6종은 이름·적용 대상·수치가 같지 않다. 예를 들어 엑셀의 지원은 포탑 공속이고 현재 지원은 최대 HP와 이동속도다. 따라서 이름만 바꾸어 이미 구현된 효과처럼 표시하지 않는다.

24종은 설명을 볼 수 있는 기획 노드로 표시하며 구매는 비활성 상태다. 비용과 일부 수치도 원본에서 미정이다. 실제 24종 효과와 밸런스 확정은 별도 작업이다.

현재 작동하는 6종 구매는 `현재 강화 6종` 버튼에서 유지한다. 기존 저장 슬롯·XP 비용·선행 조건·효과는 변경하지 않았다. `아이콘 Web 보기`로 돌아올 수 있다.

## 검증

`Rushitadel.Editor.WebTreeValidation.Run`은 격리된 저장 경로에서 24개 아이콘 로드, 각 노드 클릭, XP 미소비, 설명 변경, 일시정지, 기존 구매 및 복귀를 확인한다.
