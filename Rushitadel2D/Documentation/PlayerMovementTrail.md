# 이동 도트 잔상

- 실제 월드 이동 방향의 반대쪽에 작은 세 토막 도트 잔상을 방출한다. 마우스 조준 방향이나 포탑 자전은 방향에 영향을 주지 않는다.
- 몸체 뒤 좌우에서 0.085초 간격으로 번갈아 방출한다. 수명 0.32초, 알파 0.16에 제곱 감쇠를 적용하여 짧고 은은하게 사라진다.
- 본체 크기에 맞춘 오프셋과 기존 속성 발광색을 사용한다. 정지 상태에서는 신규 방출하지 않는다. 1유닛 이상 순간이동, 사망, 컴포넌트 비활성화 시 이동 잔상을 비운다.
- 정렬 순서 96: 본체(100)와 탄(112)보다 아래. 충돌·대미지·광원은 추가하지 않는다. 8개 이동 전용 풀로 발사 이펙트와 슬롯 경쟁을 피한다.
- 기존 PlayerFlightEffects와 FlightVfx 셰이더를 확장했다. 별도 래스터 이미지 생성은 하지 않았다.
- 자동 검사: 상하좌우 이동의 방출 여부, 반대 방향, 풀 제한, 정지 후 소멸을 검사한다. 실제 플레이에서 밝기 선호에 따른 미세 조정은 가능하다.
- 별도 Unity 복사본에서 이동 검사와 기존 탄막 회귀 검사를 포함한 461개 검사를 통과했다. 로그: output/player-trail-validation.log. 자동 검사에서 물리 보간을 끈 Rigidbody 위치 이동을 사용하며, 정지 검사에는 마지막 LateUpdate 반영 시간을 둔다.
