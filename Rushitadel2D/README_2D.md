# Rushitadel 2D

Unity **6000.5.3f1**, URP 2D, Input System. `Assets/Scenes/Title.unity`를 열고 Play를 누른 다음 **새게임**을 선택하세요. `Assets/Scenes/inGame.unity`에서 바로 Play해도 됩니다.

## 조작

- WASD: 이동 (대각선 속도 정규화)
- 마우스 왼쪽 버튼 유지: 초당 4발, 지정 위치에 피해 25 / 반경 1
- 마우스 오른쪽 버튼: 파워 20 소비, 지정 위치 반경 2.5 안의 적 즉시 처치
- ESC: 일시정지, 재개, 재시작 또는 타이틀로 이동

## 원본과의 대응

기존 XZ 좌표를 XY 좌표로 변경하고 공간 단위를 1/100로 환산했습니다. 체력, 피해량, 발사 간격, 경험치, 파워 수치는 유지합니다.

| 기능 | 2D 구현 |
| --- | --- |
| 이동 | Rigidbody2D, 중력 0, 회전 고정, 속도 2.5 |
| 일반 사격 | 속도 12, 수명 3초, 마우스 목표 위치에서 광역 피해 |
| 파워샷 | 파워 20, 반경 2.5, 시각 크기 2배, 일반 사격과 독립 |
| 타워 | 중앙 1개: 사거리 3 / 피해 25. 외곽 6개: 사거리 4 / 피해 50. 모두 간격 0.5초 |
| 유도탄 | 속도 10, 판정 거리 0.2, 수명 5초. 표적 소멸/사거리 이탈 시 재탐색, 표적이 없으면 마지막 위치로 이동 |
| 적 | 체력 100, 속도 1, 가장 가까운 타워로 접근, 거리 0.45에서 정지 |
| 생성 | 1초마다 2마리. 좌우 -9.5 / 11, Y 범위 -4~5. 파워 회복 중 3마리 |
| 경험치 | 적 처치마다 20, 플레이어로 자동 이동(속도 14), 거리 0.5에서 수집. 게이지 기준 100 |
| 파워 | 초기 100, 초당 1 소모, 0에서 회복 전환, 초당 1 회복, 60에서 소모 재개 |
| 표현 | 기존 성채/타이틀/플레이어 스프라이트와 걷기 애니메이션 재사용 |

성채 그림에 맞게 7개 타워의 발사 위치를 2D에서 정렬했습니다. 원본의 3D 캡슐 적과 탄환은 색상이 있는 2D 스프라이트로 표현합니다. 플레이어 애니메이션은 이동 중 재생하고 좌우 방향에 맞춰 반전합니다. HUD, 일시정지, 타이틀 시작/설정/종료 버튼 동작을 추가했습니다.

원본에 적의 타워 공격, 타워/플레이어 체력, 게임오버/승리, 업그레이드 선택, 저장/불러오기 로직은 없습니다. 이 포트도 그 기능을 새 게임 규칙으로 만들지 않았습니다. 원본 타이틀의 '계속하기'는 저장 기능이 없으므로 비활성화되어 있습니다. 경험치의 100 단위 갱신은 업그레이드 선택을 의미하지 않습니다.

## 구성

전투, 이동/조준, 파워, 경험치, 스폰, 표현을 별도 컴포넌트로 분리합니다. `IDamageable`, `IPowerResource`, `IEnemySpawnModifier`로 역할을 구분하고, 탄환 두 종류는 `ProjectileBehaviour`를 상속하여 공통 물리 초기화와 피해 처리 계약을 공유합니다. 파워에 따른 스폰 변경은 인터페이스로 연결됩니다. 설정 필드는 private SerializeField로 캡슐화합니다.

씬/프리팹이 이미 생성되어 있어 별도 설정 작업은 필요 없습니다. 필요할 때만 **Rushitadel 2D → Rebuild Gameplay Scene**을 사용하세요. 이 메뉴는 생성된 게임 씬/프리팹을 기본값으로 재생성하므로 해당 에셋을 직접 수정한 뒤에는 주의하세요. 에디터 재로드만으로 씬을 덮어쓰지 않습니다.

## 검증 재실행

프로젝트가 다른 Unity 에디터에서 열려 있지 않은 상태에서:

```powershell
& 'C:/Program Files/Unity/Hub/Editor/6000.5.3f1/Editor/Unity.exe' -batchmode -projectPath '<프로젝트 절대 경로>' -executeMethod Rushitadel.Editor.PortValidation.Run -logFile '<검증 로그 절대 경로>'
```

검증은 Play Mode에 진입해 실제 이동, 자동 스폰/타워 전투/경험치, XY 범위 판정, 일반탄, 파워샷 조준/소비/즉사, 파워 회복, 유도탄 재탐색을 확인하고 종료합니다. 성공 로그는 `RUSHITADEL_2D_VALIDATION_SUCCESS`입니다. `-quit`은 붙이지 마세요. 테스트 스크립트는 에디터에서만 컴파일되며 게임 빌드에는 포함되지 않습니다.
