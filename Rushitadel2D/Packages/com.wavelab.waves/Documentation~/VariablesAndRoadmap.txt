원칙
표시 이름과 ID 분리. 증강과 웹은 동일한 효과 계산 및 성장 상태를 공유한다.
정의 에셋은 편집 데이터. GrowthState는 한 판의 가변 상태. 플레이어 원본 프리팹은 변경하지 않는다.
증강/웹 모듈 없이도 웨이브 모듈을 설치·실행할 수 있어야 한다.

현재 변수
StatValue: id(string), unit(string), value(float). 예: health.max/HP, attack.damage/HP,
attack.interval/s, attack.range/world-unit, movement.speed/world-unit-per-s.
StatModifier: sourceId, statId, operation(Flat/AdditivePercent/Multiply), amount(float).
공식: clamp((base + flat 합) * (1 + percent 합) * multiplier 곱, min, max).
비율 +10%는 0.1, 곱 1.1배는 1.1. 두 표현을 혼동하지 않는다.
ResourceAmount: resourceId(string), amount(float). xp/gold 등 분리. 반올림은 게임 어댑터가 결정.
GrowthState: schemaVersion, seed, level, resources[], upgrades[definitionId/rank], purchasedNodeIds[], modifiers[].
NumericBinding: statId, unit, source(Object), propertyPath, snapshot(float), sampledUtc(UTC ISO8601).
현재 NumericBinding은 에디터 읽기 전용이다. 실행 중 최종 값은 추후 IStatProvider 어댑터로 연결한다.
EnemyProfile: id, prefab, defeatRewards[], statBindings[]. 복제 에셋 ID 충돌 정책은 후속 카탈로그에서 처리 예정.
SpawnGroup: id, enemy, spawnKey, count(1~10000), batchSize(1~10000), startSeconds(>=0), intervalSeconds(>0).
WaveDefinition: id, title, end, durationSeconds(>0), restSeconds(>=0), groups[].
WavePlan: schemaVersion=1, seed, waves[].
SpawnArea: key(씬 내 고유), shape, plane, size, innerRadius, outerRadius, follow.
WaveRunner: plan, spawnAreas[], startWaveIndex(0기준), playOnStart, safetyTimeoutSeconds.
이벤트: onWaveStarted/Completed(0기준 인덱스), onReward(resourceId, amount), onPlanCompleted, UnitSpawned.
SpawnedUnit: ReportDefeated/ReportDespawned. 최초 알림만 유효. 비처치 삭제는 보상 없음.

후속 개발 순서 (미구현)
2. 연결/스폰: 프리팹 필드 후보, 숫자 단위 변환, 계산값 어댑터, 풀 연결,
   화면 밖/경로 시작점/금지영역, 충돌 검사와 실패 정책(재시도/스킵/중지).
3. 증강: UpgradeDefinition(id/effects/prerequisites/exclusions/maxRank/offerWeight),
   선택 정책은 등장 확률과 분리. 선택 시 실제 GrowthState에 효과 추가. 저장/복원 버전 관리.
4. 웹: NodeDefinition(id/upgradeId/cost/parents/position), 생성 규칙(seed/branchCount/depth),
   선행 노드 검사, 구매 트랜잭션, 공유 효과 참조, 순환 참조 방지.
5. 분석: 빠른 기대값 계산, 시간 기반 성장 시뮬레이션, 여러 빌드/시드 비교.
   전투 모델 없이 생존율을 만들지 않는다. 미지원 규칙/가정/샘플 수를 결과에 함께 표시.
6. 자동 조정: 수정 허용 변수와 범위/잠금, 목표와 페널티, 별도 검증 시드,
   추천안 미리보기/승인/Undo. 자동으로 원본 값을 덮어쓰지 않는다.

첫 검증 대상은 독립 데모이며 러시타델 실행 시스템을 자동 교체하지 않는다.
러시타델/뱀서형/디펜스형 어댑터 예제를 후속 단계에서 추가한다.
