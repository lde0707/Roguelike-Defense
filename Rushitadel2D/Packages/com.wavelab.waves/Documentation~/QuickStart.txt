쉬운 웨이브 제작 — 2026-10-20
Tools → 웨이브랩 → 시작하기 (쉬운 자동 생성)

[제작] 1 유닛 → 2 전투 느낌 → 3 미리보기 → 4 저장·사용. 새 생성 결과를 저장하면 본편에 자동 연결됩니다. 기존 편성은 Tools → 웨이브랩 → 현재 본편 웨이브 수정에서 편집 후 저장하세요. 플레이 중 저장한 변경은 다음 라운드부터 적용됩니다.

[본편] 우리 게임 유닛 불러오기 → 9라운드 생성 → 파일 저장(본편 자동 연결) → Title에서 새 게임. 보스·정비·테마는 기존 규칙입니다. 본편에는 WaveRunner를 추가하지 마세요. 연결 해제로 기존 편성에 복귀할 수 있습니다.

[일반 테스트] 예제 불러오기 → 저장 → BattleTest 씬 열기 → 실행기에 적용 → Ctrl+S → Play. 사용자 프리팹은 사망 시 ReportDefeated(), 풀 반환 시 ReportDespawned()를 연결하세요.

[조절] 너무 어렵다: 난이도/동시 적/엘리트 상한 감소. 단조롭다: 전투 흐름/역할/비중 변경. 너무 쉽다: 실측 유효 DPS를 보정. 실측 DPS는 실제 적 체력 감소량을 전투 시간으로 나눈 값이며 탄 제거량을 더하지 않습니다.

[시간] 목표는 계획 기준이며 적 상한·배치 공간·잔여 적 정리 때문에 실제 시간은 늘어날 수 있습니다. 안전 정지 시 사망 알림과 스폰 영역 공간을 확인하세요. 휴식은 적 정리 뒤 시작합니다.

[주의] 예상 HP·회복·성장은 계산값입니다. 실제 회복이나 업그레이드를 지급하지 않습니다. 광역·도탄·탄 파괴·전투 승률은 실제 플레이로 확인하세요.

본편 프로필은 시작 체력과 스테이지별 체력 증가를 반영합니다. 본편 연결은 Resources/WaveLabCampaign.asset에 저장합니다.
스폰 안전 영역은 SpawnArea.avoid/avoidRadius, 적 사이 거리는 WavePlan.minimumSpawnSpacing에서 설정합니다.


[웨이브 보관함 · 라운드 배치]
Tools → 웨이브랩 → 웨이브 보관함 · 라운드 배치
1. 가져올 계획과 웨이브 번호를 선택합니다. 단일 웨이브를 보관함 파일(WaveTemplate)로 저장해 재사용할 수도 있습니다.
2. 대상 계획을 선택하거나 새 계획을 만듭니다. 위치 이름은 ‘1스테이지 2라운드’, ‘보스 직전’처럼 자유롭게 정합니다.
3. 대상 위치를 선택하고 맨 뒤 추가 / 앞에 삽입 / 교체를 누릅니다. 위·아래 이동과 삭제는 실행 취소가 가능합니다.
4. 배치 저장. 일반 게임은 각 씬의 WaveRunner.Plan에 해당 계획을 연결합니다. 순서대로 실행하며 startWaveIndex로 시작 위치를 지정합니다.
5. 배치한 웨이브는 독립 복사본입니다. 원본 수정은 이미 배치한 곳에 전파되지 않습니다. 갱신하려면 다시 교체하세요.
적 프로필 참조는 유지합니다. 상한·시드·최소 등장 거리는 대상 계획의 설정을 따릅니다.
공용 툴에는 테마나 라운드 개수 제한이 없습니다. 러시타델의 9라운드 검사는 본편 연결에만 적용합니다.
현재 본편에 연결된 계획을 대상에 넣고 위치를 교체한 뒤 저장하면 다음 라운드부터 반영됩니다.
보관함이나 다른 계획을 저장하는 것만으로 현재 본편 연결이 바뀌지 않습니다. 새 본편 계획은 쉬운 생성기의 본편 저장/다시 연결을 사용합니다.

[러시타델 전체 테마 프리팹]
프리팹: Assets/Prefabs/ThemedEnemies (Grass/Fire/Ice/Water/Electric 각 7종, Bosses 4종)
웨이브용 적 프로필: Assets/WaveLabThemeProfiles (같은 폴더 구성)
웨이브 그룹의 적 프로필 칸에 원하는 테마의 .asset 파일을 넣으세요. N01~N05는 일반 적, E01~E02는 엘리트이며 역할을 엘리트로 지정하세요.
테마 전용 적은 다른 배경에서도 선택한 테마의 외형과 투사체를 유지합니다. 기존 CampaignEnemies 7종은 현재 스테이지 테마를 따라갑니다.
물/전기는 현재 아트와 공격을 공유하지만 선택용 프리팹과 프로필은 각각 분리했습니다.
Bosses 프리팹은 씬에 직접 배치하거나 별도 WaveRunner 계획에서 사용할 수 있습니다. 본편 일반 9라운드에는 보스 프로필을 넣지 않습니다. 기존 본편 보스 전환은 그대로 유지합니다.
추가 생성 메뉴: Tools → 웨이브랩 → 전체 테마 적 프리팹 준비. 기존 파일은 덮어쓰지 않습니다.
