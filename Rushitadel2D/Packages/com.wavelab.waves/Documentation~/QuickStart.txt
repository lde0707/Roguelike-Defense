웨이브랩 처음 사용하기

1. Unity 상단 Tools → 웨이브랩 → 시작하기 (쉬운 자동 생성)을 누릅니다.
   기존 '자동 밸런스 초안' 메뉴와 웨이브 편집기의 '자동 생성'도 같은 쉬운 화면을 엽니다.
2. '처음 사용해요 — 예제로 채우기'를 누릅니다.
   플레이어와 전투용 적 3종이 선택됩니다. 숫자는 직접 입력할 필요가 없습니다.
   예제가 없다는 안내가 나오면 Tools → 웨이브랩 → 플레이어 전투 테스트 씬 만들기를 실행합니다.
3. '다음 — 시간과 난이도'를 누릅니다.
4. 총 플레이 시간(분)과 난이도를 고릅니다. 처음에는 5분 / 보통을 권장합니다.
5. '웨이브 만들기'를 누릅니다. 웨이브별 적 수와 전투 시간이 표시됩니다.
6. '1. 웨이브 파일 저장'을 누르고 Assets 폴더 안에 저장합니다.
   웨이브 .asset과 계산 보고서 .balance.txt가 함께 저장됩니다. 기존 파일은 덮어쓰지 않습니다.
7. '2. 전투 테스트 씬 열기'를 누릅니다. 다른 씬에 미저장 변경이 있으면 저장 여부를 묻습니다.
8. '3. 저장한 웨이브 적용'을 누릅니다.
9. Ctrl+S로 씬을 저장하고 Unity 상단 ▶ Play를 누릅니다.
   플레이어가 자동으로 적을 찾아 공격합니다. HP, 처치 수, XP, 골드를 확인하세요.

내 게임에 사용하기
- 첫 화면의 플레이어 프리팹과 적 프로필을 교체합니다.
- 적은 프리팹 자체가 아니라 적프로필.asset을 넣습니다. 프로필에 프리팹과 보상이 연결돼 있습니다.
- 읽을 수 없는 스크립트는 '고급 설정이 필요해요'에서 스탯 필드 연결 또는 수동 입력을 사용합니다.
- 테스트 씬을 여는 대신 내 씬의 WaveRunner를 '적용할 실행기'에 끌어 넣어 적용할 수도 있습니다.
- 적용 버튼은 웨이브 계획과 자동 시작만 변경합니다. 플레이어 교체나 스폰 영역 생성은 하지 않습니다.
- 계산에 사용한 플레이어와 실제 씬의 플레이어를 같게 맞추고 스폰 영역도 연결해야 합니다.

처음에는 보이지 않는 항목
쉬운 화면은 성장 계산 끔, 휴식 5초, 조우 거리 6유닛을 사용합니다.
명중률과 가동률도 기본 가정값을 사용합니다. 실제 전투를 시뮬레이션한 확정 밸런스는 아닙니다.
성장 계산, 웨이브 수 고정, 조우 거리, 스폰 키, 명중률, 보상, 수동 스탯은 고급 창에서 수정합니다.
고급 창은 쉬운 화면의 설정을 복사해서 시작하며, 변경을 쉬운 화면에 역으로 덮어쓰지 않습니다.
고급 창에서 만든 결과는 고급 창에서 저장하고 웨이브 편집기의 테스트 연결을 사용합니다.

주의

실제 전투는 Assets/WaveLabBattle/BattleTest.unity에서 확인하세요.
