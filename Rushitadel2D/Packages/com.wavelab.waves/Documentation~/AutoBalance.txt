자동 밸런스 초안 사용법

Tools > 웨이브랩 > 자동 밸런스 초안 (또는 웨이브 편집기 상단 ‘자동 생성’)
1. 총 목표 시간과 난이도를 선택합니다. 웨이브 수 0은 자동 결정입니다.
2. 플레이어 시작 체력, 1회 피해, 공격 간격, 명중률, 공격 가능 시간 비율을 입력합니다.
3. 적 프로필을 추가하고 체력/피해/공격 간격/명중률과 스폰 영역 이름을 입력합니다.
   적 프로필의 읽어 둔 health.max / attack.damage / attack.interval 스냅샷을 가져올 수 있습니다.
   보상은 프로필의 defeatRewards에서 xp/gold만 읽습니다. 다른 자원은 실행에 남지만 성장 계산에서 제외합니다.
4. 예상 업그레이드 반영을 켜고 경험치 곡선과 공격력 증가율, 골드 비용을 설정합니다.
5. 웨이브 자동 생성 → 결과 검토 → 새 웨이브 계획으로 저장.
   원본 프리팹/스탯/기존 계획은 변경하지 않으며 결과 옆에 .balance.txt 보고서를 저장합니다.
   입력을 바꾸면 이전 결과가 폐기되므로 다시 생성해야 합니다.

계산 변수와 수식
유효 DPS = 1회 피해 / 공격 간격 * 명중률 * 공격 가능 시간 비율.
자동 웨이브 길이 기준 = clamp(30 + 2 * 평균 적 HP / 시작 유효 DPS, 20, 90)초.
자동 웨이브 수 = round((총 시간 + 휴식)/(길이 기준 + 휴식)), 1~100 제한.
전투 시간 = (총 시간 - (웨이브 수 - 1)*휴식)/웨이브 수. 최소 5초.
난이도별 화력 예산 비율: 쉬움 .45 / 보통 .6 / 어려움 .75.
난이도별 웨이브 예상 피해 상한: 최대 HP의 .12 / .22 / .35.
진행에 따른 예산 배율: 첫 .8 → 마지막 1.2 (1웨이브는 1.0).
후보 적의 예상 피해 = 적 피해 / 적 공격 간격 * 적 명중률 * 적 HP / 유효 DPS.
두 예산에 들어가는 후보를 동일 확률로 선택하며 더 들어갈 수 없을 때 종료합니다.
적 수 상한: 웨이브당 min(10000, floor(전투 초*100)).
목표 예산에 한 마리도 들어가지 않으면 생성을 거부하고 조정 안내를 보여줍니다.
생성 계획은 시간 종료 방식. 마지막 적을 처리할 시간을 남기도록 등장 간격을 배치합니다.
각 적 그룹은 첫 시점에 시작하므로 실제 동시 공격에 따른 피해는 모델과 다를 수 있습니다.

성장 모델 (자동 게임 적용 아님)
웨이브 종료 시 모든 적을 처치했다고 가정하여 경험치/골드를 획득합니다.
다음 레벨 필요 XP = 첫 요구량 * (1 + 요구량 증가율*(현재 레벨-1)).
가능한 레벨업을 모두 처리하며 레벨 100 상한입니다.
골드는 고정 비용의 공격력 강화에 모두 소비. 누적 100회 상한입니다.
다음 웨이브 DPS = 시작 DPS * (1 + (레벨-1)*레벨당 증가율 + 누적 구매수*구매당 증가율).
성장 미반영 시 레벨 1, 구매 0, 시작 DPS로 계속 계산합니다.
실제 게임의 레벨업/구매 시스템은 별도로 동일 규칙에 연결해야 합니다.

한계
자동 생성은 예산 기반 기대값 초안입니다. 최적화나 실제 전투 반복 검증이 아닙니다.
사거리·이동·도탄·탄 파괴·범위·회피·우선순위·특수 증강·웹은 미지원.
공격 가능 시간 비율은 사용자가 추정하는 대체 변수이며 실제 사거리 계산이 아닙니다.
전체 HP 소모 누적/회복/생존 확률을 계산하지 않습니다. 예상 피해는 웨이브별 비교 값입니다.
희귀도/보스/적 편성 가중치/여러 업그레이드 선택 정책은 다음 단계입니다.
목표 시간은 계획 시간 합계이며 실제 종료는 잔여 적 처리로 늦어질 수 있습니다.
