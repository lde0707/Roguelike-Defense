WaveLab 0.1 — 웨이브 기반 기능 (Unity 6)

설치
현재 프로젝트 Packages 폴더의 embedded package로 구성했습니다.
다른 프로젝트에는 com.wavelab.core와 com.wavelab.waves 두 폴더를 Packages에 복사합니다.
이 단계에서는 러시타델 코드/씬/프리팹에 의존하지 않습니다. Unity 6000.5.3f1에서 검증합니다.

가장 빠른 실행
Tools > WaveLab > Create Separate Demo Scene
현재 씬 저장 여부를 확인한 뒤 Assets/WaveLabDemo(중복 시 새 이름)에 독립 데모를 생성합니다.
Play: 3개 웨이브가 등장하고 큐브가 2초 뒤 자동 처치됩니다. 실제 전투 검증은 아닙니다.
Tools > WaveLab > Wave Editor를 열고 DemoPlan을 넣으면 실행 상태를 볼 수 있습니다.

실제 적 연결
1. Wave Editor의 적 등록: EnemyProfile을 저장하고 기존 프리팹을 지정합니다.
2. 스탯 연결: 기존 Component/ScriptableObject를 지정하고 숫자 필드 선택 > 현재 값 읽기.
   스탯은 읽기 전용 스냅샷입니다. 런타임 스탯을 수정하거나 자동 분석하지 않습니다.
   GameObject를 넣으면 컴포넌트 목록을 제공합니다. 자식 컴포넌트는 직접 지정하세요.
3. 새 플랜 > 웨이브 > 적 그룹 추가. 프로필, 수, 첫 등장, 배치 간격, 배치 수, 영역 키를 설정합니다.
4. 씬에 SpawnArea와 WaveRunner를 추가합니다. Runner의 plan과 spawnAreas를 연결합니다.
5. 기존 적의 사망 처리에서 삭제 전에 다음을 호출하세요:
   GetComponent<WaveLab.Waves.SpawnedUnit>()?.ReportDefeated();
   도주/풀 반환/비처치 제거는 ReportDespawned()를 호출하세요.
   자동 Destroy는 비처치 제거로 취급하며 보상을 주지 않습니다.
6. onReward(resourceId, amount)를 기존 경험치/골드 시스템에 연결합니다.
   기존 적이 이미 보상을 주면 defeatRewards를 비워 중복 지급을 피하세요.
7. Play 모드에서 선택 웨이브부터 실행. 시작 성장 상태는 현재 씬 상태이며 자동 복원하지 않습니다.

실행 규칙
시간은 Time.deltaTime 기반(일시정지/배속 영향). 위치 추첨만 seed로 재현합니다.
웨이브별 그룹은 병렬이며 첫 등장 시간은 해당 웨이브 시작 기준입니다.
마지막 등장 = 시작 시간 + floor((count-1)/batchSize) * intervalSeconds.
한 프레임 생성 상한은 256개입니다. 밀린 등장은 이후 프레임에 처리하므로 고밀도 실행은 지연될 수 있습니다.
시간 종료도 예정된 등장이 전부 처리된 후 완료합니다.
AllDefeated는 앞 웨이브에서 넘어온 적까지 포함한 잔여 적 0을 기다립니다. 도주/반환도 잔여 수에서 빠집니다.
AllSpawned/Duration은 잔여 적을 다음 웨이브로 넘깁니다. 전체 플랜 완료는 잔여 적이 없어야 발생합니다.
안전 타임아웃은 중지이며 클리어나 보상으로 처리하지 않습니다.
Stop은 실행기가 생성하고 아직 추적 중인 적만 제거합니다. 기존 씬 적은 건드리지 않습니다.
실행 시작 시 플랜/보상은 복사합니다. 편집용 에셋은 런타임 상태로 사용하지 않습니다.

스폰 영역
Point / Rectangle / Annulus 지원. XY(탑뷰 2D)와 XZ(3D 바닥)를 선택합니다.
follow 지정 시 중심 = follow.position + 영역 Transform.position(월드 오프셋).
장애물/금지 영역/화면 밖/경로/유효 위치 재시도는 다음 단계입니다.
기존 프리팹의 Awake/OnEnable이 생성 순간 작동합니다. 생성 직후 알림은 UnitSpawned 이벤트로 받습니다.
생성 즉시 자기 삭제하는 프리팹, 커스텀 풀/네트워크 스폰은 별도 팩토리 연결이 필요하며 현재 미지원입니다.

미지원 (완료로 오해하지 말 것)
자동 밸런싱, 성장 시뮬레이션, 레벨업 선택, 웹 편집, 타임라인 UI, 전투 AI, 수치 자동 적용,
기존 게임의 계산 프로퍼티 추론, 플레이 로그 분석은 아직 구현하지 않았습니다.
공통 GrowthState/StatModifier/IStatProvider/IRewardReceiver는 후속 모듈을 위한 계약입니다.

테스트
Unity Test Runner에서 WaveLab.Waves.Tests 실행.
EditMode: 스탯 순서/상한, 배치 시간, 검증, 원형 위치 시드, 중복 처치, 비처치 제거.
PlayMode: 실제 생성/보상/완료, Stop 시 무보상, 원본 변경과 실행 복사본 분리.
