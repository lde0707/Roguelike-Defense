웨이브랩 자동 전투 예제

Assets/WaveLabBattle/BattleTest.unity를 열고 Play를 누르세요.
또는 Tools > 웨이브랩 > 플레이어 전투 테스트 씬 만들기로 새 예제를 만듭니다.
기존 데모 씬과 설정은 덮어쓰지 않습니다. 이전 DemoEnemy는 여전히 2초 자동 삭제용입니다.

플레이어: HP 250, 피해 20, 공격 간격 0.4초, 사거리 6, 이동속도 2.
가장 가까운 적을 자동으로 추적하고 공격합니다. 수동 조작 플레이어가 아니라 밸런스 관찰용입니다.
약한 적: 원거리 / 빠른 적: 근거리 / 튼튼한 적: 근거리.
근접 사거리 0.9. 원거리 적 사거리 3.

프리팹의 Example Combat > 공격 방식에서 근거리/원거리를 선택합니다.
Example Enemy에 체력, 피해, 공격 간격, 이동속도, 사거리를 입력합니다.
플레이어 팀은 플레이어만 켭니다. 자동 추적 이동을 끄면 제자리에서 공격합니다.
기존 예제 적에도 Example Combat을 추가하면 참여합니다. DemoLifetime과 함께 사용하지 마세요.

근거리: 중심 간 거리가 사거리 이내일 때 직접 피해 + 짧은 타격 표시.
원거리: 발사 시 방향을 고정한 탄. 경로상의 반대 팀을 맞히고 사거리 끝에서 삭제.
피해로 HP가 0이 되면 처치, 웨이브 보상 이벤트를 받아 HUD에 XP/골드 합산.
플레이어가 죽으면 웨이브 정지. 재시작은 Play를 껐다 켜세요.

범위: XY 평면 단순 전투 검증 예제입니다. 장애물, 도탄, 경로 탐색, 업그레이드 자동 구매는 없습니다.
플레이어와 적 능력치 변경은 자동 밸런스 창에 자동 동기화되지 않습니다.
적 프로필의 스탯 다시 읽기와 플레이어 입력값 확인 후 웨이브를 생성하세요.
현재 자동 밸런스 계산은 DPS 근사이며, 근거리 접근 시간/원거리 빗나감은 실제 테스트와 차이가 납니다.
