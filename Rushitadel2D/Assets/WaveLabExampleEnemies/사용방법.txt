웨이브랩 예시 적 3종

01_약한적: 체력 30 / 공격 피해 2 / 간격 2.5초 / 이동속도 1 / 사거리 3 / 경험치 10 / 골드 3
02_빠른적: 체력 50 / 공격 피해 3 / 간격 1.5초 / 이동속도 3 / 사거리 3 / 경험치 18 / 골드 5
03_튼튼한적: 체력 160 / 공격 피해 8 / 간격 3초 / 이동속도 0.6 / 사거리 4 / 경험치 40 / 골드 12

자동 밸런스 창에서 ‘적 추가’를 누르고 *_적프로필.asset을 적 프로필 칸에 넣으세요.
‘프로필의 저장된 스탯 가져오기’를 눌러 체력/공격 피해/간격을 가져옵니다.
플레이어에게 맞힐 비율과 스폰 영역 이름은 사용자가 지정합니다.
이동속도와 사거리는 예시 스탯으로 저장되지만 현재 자동 계산에서는 사용하지 않습니다.
프리팹 스탯을 바꾼 경우 적 프로필에서 ‘현재 값 읽기’ 후 자동 생성 창에서 다시 가져오세요.

씬 스폰 테스트: 프리팹은 원점으로 이동하지 않으며 기본적으로 자동 이동은 꺼져 있습니다.
ExampleEnemy 인스펙터에서 ‘자동 이동 사용’을 켜면 지정 방향으로 직선 이동합니다.
플레이 중 ‘테스트: 피해 10’, ‘테스트: 처치’ 버튼으로 체력과 처치 보상을 확인할 수 있습니다.
실제 공격 AI/투사체는 없습니다. 러시타델 공격 시스템과 자동 연동되지 않습니다.
게임의 피격 코드에서 ExampleEnemy.TakeDamage(피해량)를 호출해야 합니다.
웨이브 실행기로 생성된 적을 처치하면 프로필의 보상이 onReward로 한 번 전달됩니다.
onReward를 실제 경험치/골드 시스템에 연결해야 자원이 증가합니다.
이전 DemoLifetime과 달리 일정 시간이 지났다고 자동으로 처치되지는 않습니다.
