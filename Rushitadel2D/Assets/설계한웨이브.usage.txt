대상: Rushitadel 본편 일반 라운드
[제작] 1 유닛 → 2 전투 느낌 → 3 미리보기 → 4 저장·사용. 변경 후에는 다시 생성하고 새 계획을 적용하세요.

[본편] 우리 게임 유닛 불러오기 → 9라운드 생성 → 파일 저장 → 본편에 적용 → Title에서 새 게임. 보스·정비·테마는 기존 규칙입니다. 본편에는 WaveRunner를 추가하지 마세요. 연결 해제로 기존 편성에 복귀할 수 있습니다.

[일반 테스트] 예제 불러오기 → 저장 → BattleTest 씬 열기 → 실행기에 적용 → Ctrl+S → Play. 사용자 프리팹은 사망 시 ReportDefeated(), 풀 반환 시 ReportDespawned()를 연결하세요.

[조절] 너무 어렵다: 난이도/동시 적/엘리트 상한 감소. 단조롭다: 전투 흐름/역할/비중 변경. 너무 쉽다: 실측 유효 DPS를 보정. 실측 DPS는 실제 적 체력 감소량을 전투 시간으로 나눈 값이며 탄 제거량을 더하지 않습니다.

[시간] 목표는 계획 기준이며 적 상한·배치 공간·잔여 적 정리 때문에 실제 시간은 늘어날 수 있습니다. 안전 정지 시 사망 알림과 스폰 영역 공간을 확인하세요. 휴식은 적 정리 뒤 시작합니다.

[주의] 예상 HP·회복·성장은 계산값입니다. 실제 회복이나 업그레이드를 지급하지 않습니다. 광역·도탄·탄 파괴·전투 승률은 실제 플레이로 확인하세요.
